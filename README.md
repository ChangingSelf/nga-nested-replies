# NGA 楼中楼脚本 v2.0.3

## 功能概述

这是一个优化的NGA论坛楼中楼脚本，支持渐进式加载、智能缓存和配置管理，极大提升了大型帖子的浏览体验。

## 新版本特性

### 🚀 渐进式加载

- **快速展示**：加载指定页数后立即转换显示，无需等待所有页面加载完成
- **后台预加载**：用户阅读时，脚本在后台继续加载更多页面
- **默认配置**：初始加载5页，后台预加载10页（可自定义）

### 💾 智能缓存系统

- **自动缓存**：已加载的页面自动缓存到本地
- **快速恢复**：24小时内重新打开帖子，秒速展示缓存内容
- **有效期管理**：支持1小时/12小时/24小时/7天/永久缓存
- **缓存清理**：自动清理过期缓存，支持手动管理

### 🎨 可视化配置面板

- **悬浮按钮**：页面右下角齿轮图标，点击打开配置面板
- **加载配置**：自定义初始加载页数（1-50）和预加载页数（0-100）
- **缓存管理**：查看所有缓存帖子，显示占用空间、访问时间、有效状态
- **一键清理**：支持单个帖子删除和全部清空

### 📜 滚动追加加载

- **智能检测**：滚动到底部自动加载更多内容
- **无缝体验**：后台加载，用户无感知
- **进度提示**：底部显示加载状态

## 使用方法

### 安装

1. 安装 Tampermonkey 浏览器扩展
2. 安装本脚本
3. 打开任意NGA帖子，脚本自动运行

### 配置

1. 点击页面右下角的⚙️图标
2. 在"加载配置"选项卡中：
   - 设置初始加载页数（建议3-10页）
   - 设置预加载页数（建议5-20页）
3. 在"缓存管理"选项卡中：
   - 查看所有缓存的帖子
   - 删除不需要的缓存
   - 设置缓存有效期
4. 点击"保存配置"，刷新页面生效

### 工作流程

#### 首次访问帖子

1. 脚本加载指定页数（默认5页）
2. 立即转换为楼中楼形式并展示
3. 后台继续加载更多页面（默认再加载10页）
4. 滚动到底部时自动加载下一批

#### 再次访问帖子（24小时内）

1. 检测到缓存，直接展示缓存内容（秒开）
2. 后台补充加载缺失的页面
3. 更新最后访问时间

#### 长帖子阅读

1. 初始展示前5页内容
2. 用户阅读时，后台已预加载到第15页
3. 滚动到底部，立即展示第6-10页
4. 同时后台继续预加载第16-25页
5. 循环往复，直到全部加载完成

## 性能优化

### 内存管理

- 已展示内容保留在DOM中
- 未展示内容仅保存在缓存中
- 避免一次性加载造成浏览器卡顿

### 网络优化

- 并发加载多个页面
- 30秒超时自动跳过
- 失败页面不影响后续加载

### 缓存优化

- 元数据和页面内容分开存储
- 过期缓存自动清理
- 支持手动管理释放空间

## 技术实现

### 配置管理（ConfigManager）

```javascript
defaultConfig = {
  initialLoadPages: 5, // 初始加载页数
  preloadPages: 10, // 预加载页数
  cacheExpireTime: 86400000, // 24小时
};
```

### 缓存管理（CacheManager）

```javascript
// 元数据缓存
NGA_THREAD_META_{tid} = {
    tid, totalPages, cachedPages,
    lastAccess, cacheTime
}

// 页面内容缓存
NGA_PAGE_CONTENT_{tid}_{page} = {
    page, rawHTML, timestamp
}
```

### 配置面板（ConfigPanel）

- 悬浮按钮入口
- 双标签页设计（加载配置 + 缓存管理）
- 实时统计显示
- Toast提示反馈

## 已知问题

1. **GM存储限制**：缓存过多帖子可能接近存储上限，建议定期清理
2. **首次加载时间**：大型帖子（100+页）首次完整加载仍需较长时间
3. **增量转换**：当前每次追加加载都会重新渲染整个楼中楼结构
