# NGA 楼中楼脚本 v2.2.0

## 功能概述

这是一个基于TypeScript的NGA论坛楼中楼脚本，支持渐进式加载、智能缓存、虚拟滚动和配置管理，极大提升了大型帖子的浏览体验。

## 核心特性

### 🚀 渐进式加载
- **快速展示**：加载指定页数后立即转换显示，无需等待所有页面加载完成
- **后台预加载**：用户阅读时，脚本在后台继续加载更多页面
- **默认配置**：初始加载5页，后台预加载10页（可自定义）

### 💾 智能缓存系统
- **自动缓存**：已加载的页面自动缓存到本地
- **快速恢复**：24小时内重新打开帖子，秒速展示缓存内容
- **有效期管理**：支持1小时/12小时/24小时/7天/永久缓存
- **缓存管理**：可视化缓存管理界面，自动清理过期缓存

### ⚡ 虚拟滚动
- **自动启用**：超过500楼自动切换到虚拟滚动模式
- **性能优化**：只渲染可见区域，大幅减少内存占用
- **流畅体验**：可配置缓冲区大小，平衡性能和流畅度

### 🎨 可视化配置面板
- **悬浮入口**：页面右下角齿轮图标，点击打开配置面板
- **加载配置**：自定义初始加载页数（1-50）和预加载页数（0-100）
- **缓存管理**：查看所有缓存帖子，显示占用空间、访问时间、有效状态
- **性能设置**：调整虚拟滚动参数和页面加载间隔

## 使用方法

### 安装

1. 安装 Tampermonkey 浏览器扩展
2. 安装本脚本
3. 打开任意NGA帖子，脚本自动运行

### 配置

1. 点击页面右下角的⚙️图标
2. 在"加载配置"选项卡中：
   - 设置初始加载页数（建议3-10页）
   - 设置预加载页数（建议5-20页）
3. 在"缓存管理"选项卡中：
   - 查看所有缓存的帖子
   - 删除不需要的缓存
   - 设置缓存有效期
4. 点击"保存配置"，刷新页面生效

### 工作流程

#### 首次访问帖子

1. 脚本加载指定页数（默认5页）
2. 立即转换为楼中楼形式并展示
3. 后台继续加载更多页面（默认再加载10页）
4. 滚动到底部时自动加载下一批

#### 再次访问帖子（24小时内）

1. 检测到缓存，直接展示缓存内容（秒开）
2. 后台补充加载缺失的页面
3. 更新最后访问时间

#### 长帖子阅读

1. 初始展示前5页内容
2. 用户阅读时，后台已预加载到第15页
3. 滚动到底部，立即展示第6-10页
4. 同时后台继续预加载第16-25页
5. 循环往复，直到全部加载完成

## 性能优化

### 内存管理

- 已展示内容保留在DOM中
- 未展示内容仅保存在缓存中
- 避免一次性加载造成浏览器卡顿

### 网络优化

- 并发加载多个页面
- 30秒超时自动跳过
- 失败页面不影响后续加载

### 缓存优化

- 元数据和页面内容分开存储
- 过期缓存自动清理
- 支持手动管理释放空间

## 技术实现

### 配置管理（ConfigManager）

```javascript
defaultConfig = {
  initialLoadPages: 5, // 初始加载页数
  preloadPages: 10, // 预加载页数
  cacheExpireTime: 86400000, // 24小时
};
```

### 缓存管理（CacheManager）

```javascript
// 元数据缓存
NGA_THREAD_META_{tid} = {
    tid, totalPages, cachedPages,
    lastAccess, cacheTime
}

// 页面内容缓存
NGA_PAGE_CONTENT_{tid}_{page} = {
    page, rawHTML, timestamp
}
```

### 配置面板（ConfigPanel）

- 悬浮按钮入口
- 双标签页设计（加载配置 + 缓存管理）
- 实时统计显示
- Toast提示反馈

## 已知问题

1. **首次加载时间**：大型帖子（100+页）首次完整加载仍需较长时间
2. **内存使用**：超大帖子（1000+楼）在非虚拟滚动模式下可能占用较多内存
3. **翻页加载**：翻页加载时，页面内容会重复加载。非第一页开始加载会错误拼接
