## 技术细节

### 模块划分原则

1. **职责单一**：每个模块负责一个独立功能
2. **低耦合**：模块间依赖最小化
3. **高内聚**：相关功能集中在同一模块

### 打包流程

```
[源代码模块] → [build.js读取并合并] → [单文件输出] → [Tampermonkey安装]
```

**关键步骤**：
1. 读取所有模块文件（helpers, config, cache, progress）
2. 从main.js提取未模块化部分（从第279行开始）
3. 添加Tampermonkey头部和尾部
4. 输出为单文件用户脚本

### 模块依赖关系

```
┌─────────────────┐
│  helpers.js     │  工具函数（无依赖）
└─────────────────┘
         ↑
         │
┌─────────────────┐
│  config.js      │  依赖：GM_getValue/GM_setValue
└─────────────────┘
         ↑
         │
┌─────────────────┐
│  cache.js       │  依赖：config.js, GM_*
└─────────────────┘
         ↑
         │
┌─────────────────┐
│  progress.js    │  依赖：DOM API
└─────────────────┘
         ↑
         │
┌─────────────────┐
│  main.js        │  组装所有模块
└─────────────────┘
```
